# lib/email/

Adaptador de email transaccional (lembretes semanais, autenticação, avisos de plano).

**Fase 5.** Nenhum SDK instalado, nenhum serviço contratado nesta fase.

Quando existir: os modelos de mensagem ficam versionados aqui, e o envio passa sempre pelo adaptador
para que trocar de fornecedor seja alterar um ficheiro.
